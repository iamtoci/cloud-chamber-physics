# Cloud Chamber

A single-page interactive simulation for IGCSE physics students. It shows the characteristic clues left by alpha particles, beta particles and cosmic muons in a cloud chamber, and explains how ionisation makes condensation trails visible.

The tracks are stylised examples for learning. Their appearance is evidence, not a certain identification of a real particle.

## Run locally

```sh
npm run dev
```

Open `http://localhost:3000`. No dependencies or build step are required. Check the JavaScript with `npm run check`.

## Physics reference

The track descriptions follow [CERN S'Cool LAB's cloud chamber guide](https://scoollab.web.cern.ch/sites/default/files/documents/20200521_JW_DIYManual_CloudChamber_v7.pdf).
